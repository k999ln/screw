# Screw

### NoelleのGrapheneOS導入へ、迷わず進む。

![Screw。Noelleの導入ページへ進むアニメーション](assets/cover-screw.gif)

**Screw**は、Noelleが作った**PRIVATE/PIXEL**のGrapheneOS導入システムを見つけるための独立した案内リポジトリです。

**[▶ Noelleの導入ページを開く](https://privatepixel.uk/grapheneos-install)** · **[📖 導入ガイドを見る](https://privatepixel.uk/guide)**

## どんな役に立つか

PixelにGrapheneOSを導入したい人が、提供元の最新案内へ直接進めます。対象端末、準備、バックアップ、手順、サポート条件は、作業前にNoelleのページで確認してください。

| 入口 | できること |
| --- | --- |
| [導入ページ](https://privatepixel.uk/grapheneos-install) | Noelleが提供する導入システムの現在の案内を確認する |
| [ガイド](https://privatepixel.uk/guide) | 対象端末と導入前の準備を確認する |
| [RockstarOS / avocadoMini](https://github.com/k999ln/rock) | 別製品であるRockの構想と開発状況を見る |

## 提供元と範囲

- 導入システムの提供元は**Noelle / PRIVATE/PIXEL**です。
- ScrewはRock側の案内名です。PRIVATE/PIXELのソース、インストーラー、GrapheneOSのOSイメージは、このリポジトリに含めていません。
- ScrewはGrapheneOS公式プロジェクトではありません。実機への導入をRock側で検証・代行したという表示でもありません。
- このリポジトリのGIFはScrew用に新しく制作した画像です。Noelleの非公開素材を複製したものではありません。

導入時は端末の対応状況とデータのバックアップを確かめ、提供元の最新の説明に従ってください。
